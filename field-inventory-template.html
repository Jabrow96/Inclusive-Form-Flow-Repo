F2 · Task and data plan

This inventory covers the ten purposeful controls in the Community Skills Workshop registration form. The disabled button and static error specimen are state examples, not submitted data controls.

Why each workshop-request value is needed
Visible label / question Why necessary now? Required? Native control/type Submitted name/value Autocomplete/inputmode Constraint/instruction Sensitivity and minimization decision
Full name Lets the center address the confirmation and match the request to a seat. Yes Text input full_name autocomplete="name" Required; browser text entry. Basic identifying information. Collect one name only; no date of birth or ID.
Email address Provides the primary route for the confirmation or wait-list message. Yes Email input email autocomplete="email" Required; native email format; example is shown. Contact information. Needed for the stated next step and not used for marketing.
Phone number (optional) Offers a second response route when an email reply is difficult. No Telephone input phone autocomplete="tel", inputmode="tel" Optional; no rigid pattern so local formats remain possible. Contact information. Optional to minimize collection.
Workshop topic Places the person in the correct limited-capacity session. Yes Select workshop: online-safety, job-search, or video-calls Not applicable Required; choose one listed topic. Preference, not sensitive. Only current workshop choices are offered.
Preferred date Helps schedule the request in a realistic upcoming session. Yes Date input preferred_date Not applicable Required; instruction asks for a date at least one week away. Scheduling information. No recurring availability or calendar history is collected.
How will you attend? — In person Allows the center to plan room space for the selected delivery mode. Yes, as part of the group Radio input attendance: in-person Not applicable Required group; select exactly one option. Access preference. This value is limited to the workshop's delivery modes.
How will you attend? — Online Allows the center to plan an online meeting link for the selected delivery mode. Yes, as part of the group Radio input attendance: online Not applicable Required group; select exactly one option. Access preference. This value is limited to the workshop's delivery modes.
Learning goal Helps the facilitator prepare a relevant beginner activity. Yes Textarea learning_goal Not applicable Required; maximum 500 characters; do not include private information. Free-text detail can be sensitive. Limit length and explicitly discourage secrets.
Accessibility support option Signals that a follow-up about available access support may be useful. No Checkbox accessibility_support: requested Not applicable Optional; check only if contact about an option is wanted. Potentially sensitive access information. Ask only whether follow-up is wanted, not for a diagnosis.
Fictional-information acknowledgement Confirms the prototype's privacy boundary before a request is attempted. Yes Checkbox privacy_acknowledged: yes Not applicable Required; must be checked to submit. Not personal data. This protects the assessment boundary and is not retained.
